## Overview

This project lets you design a virtual drum using signed distance functions (SDFs), which describe the drum’s shape by distinguishing its interior, surface, and exterior. It uses spectral geometry to compute the shape’s eigenmodes, the patterns in which it naturally vibrates.

The project uses the frequencies associated with those modes to synthesize the sound of a strike. Change the shape and listen to how its resonances change.
